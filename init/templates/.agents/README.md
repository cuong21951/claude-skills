# Private Secret Memory

Local only. Never committed, never pasted into docs, evidence, commits, PRs or work items.

- One file per system and environment: `<system>-<env>-memory.md` (URL, account, password, notes) or `<system>.env`.
- Docs and skills reference the path, never the value.
- After a login works or fails, add a one-line note to the matching file: `verified working <date>` or `wrong as of <date>`.
